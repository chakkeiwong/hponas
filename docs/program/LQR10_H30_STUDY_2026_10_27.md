# RL-LQR-04: ten-state, thirty-step joint SAC tuning

## Authorized scope and scientific question

The user requests a higher-dimensional case: ten states and horizon thirty.
This is a successor to RL-LQR-03, not evidence that the previous SAC policy
converged. Preserve every predecessor source, result and negative outcome.
Use the same cyclic stable dynamics, one bounded continuous action, quadratic
cost, initial/noise law, discount and joint actor/critic architecture and rate
space, extended explicitly to ten states. No sibling runtime dependencies.

## Reviewed sequence

1. CONTRACT: register the successor and freeze the model, estimator, seeds and
   bounded work. Review feasibility of the analytical benchmark.
2. ENGINEERING: implement an independent optional ten-state companion, reusing
   the qualified SAC learner and repaired population procedure without changing
   predecessor bytes. Test dimensions, terminal discount, independent quadratic
   reference, sampler, objective accounting, checkpoint isolation and replay.
3. STUDY: run three paired complete BG-PBT and static procedures, with the same
   initial configurations/seeds within each pair. Retain every checkpoint and
   select on validation paths; evaluate each frozen winner on separate test
   paths. Report all three pairs, including unfavorable outcomes.
4. AUDIT: independently reconstruct oracle, costs, work, source hashes, selected
   artifacts and holdout isolation. Refresh the master and document actual
   scientific limitations; pass/fail of implementation is separate from learning.

## Evaluation review

The original complete-law enumeration would require 2^(10+30) paths and is
inappropriate. Riccati recursion and independent condensed quadratic elimination
remain inexpensive and exact up to floating-point arithmetic. Propagate linear
closed-loop coefficients to bound every oracle action over all initial/noise
signs; call the oracle attainable only if that bound is within the action box.

For learned policies use the quadratic performance-difference integrand as a
nonnegative, variance-reduced estimator of expected excess cost. Add its sample
mean to the analytic optimum to estimate total cost. Validation samples are
fixed common random numbers. Final test paths are disjoint random streams,
used only after checkpoint selection. Report sampling uncertainty, direct
rollout diagnostics, per-time-step regret and limits; do not label sampled
costs exact or certify global neural optimality. Check the expectation identity
by exhaustive evaluation on a small independent model.

## Resource envelope and continuation

Three search seeds: 10301, 10302, 10303. Four initial members and four rounds
per procedure, 4096 transitions per main segment, four architecture candidates
and two survivors. Preserve actor/critic depths 2--4, widths 8--64, independent
log-continuous learning rates 1e-5--1e-2, and upstream SAC training controls.
Validation: 1024 paths, seed 1030001. Final test: 16384 paths, seed 1030002.
No result-dependent expansion, no full-space search, no automatic repeats of
successful allocation. Two single-thread CPU workers plus a coordinator;
16 GiB owned RSS, 8 GiB output ceiling, 8 GiB free-disk floor, 3600 seconds for
the study. CPU execution avoids GPU contention for these small networks; the
previous shared-GPU qualification remains separate. No idle-GPU requirement.

At phase boundaries repair demonstrated implementation defects, retain failed
receipts, refresh the next bounded step and continue. No human-selected
success threshold: report measured optimality gaps and uncertainty.
