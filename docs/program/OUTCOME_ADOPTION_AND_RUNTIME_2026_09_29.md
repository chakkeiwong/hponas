## Executed implementation

`validation/tier0_rank_campaign.py` implements a staged artifact path:

1. Verify the search identities and measured budget, reproduce method suggestions, and hash-check all policy, recipe and training-curve bytes. Validate raw search episodes against the recorded objective. Policies and their adjacent loader recipes must be inside the campaign directory and match the bound execution recipe before any trusted checkpoint load.
2. Freeze the whole planned Cartesian product of entry/task/vector/arm slots, including absent studies, then persist each search-selected incumbent plan and a single freeze receipt. All plans precede protected evaluations in that bundle. A second freeze cannot replace the first after outcomes become visible.
3. Evaluate each distinct selected policy once with its reserved protected episode seeds. The evaluator is injected for inert CPU fixtures; actual Brax evaluation is reached through the phase-certified campaign path. No protected score is passed to an optimizer. Retain all episode slots and nonfinite/failure categories. A malformed evaluator output is an integrity error.
4. Measure protected evaluation time separately, stop launching when its allocation or remaining campaign budget is exhausted, charge in-flight work and mark overshoot. Persist failed evaluation receipts without retrying a seed or replacing a selected policy. This is a cooperative launch cap; an enforceable strict wall limit still belongs to the actual allocated execution environment.
5. Independently reload and recheck every artifact, rebuild each plan from search scores, reconstruct the protected curve without reselection, retain missing intervals and aggregate equal task weights into complete seed vectors. Recompute final/anytime components, the entry IUT and Holm decisions. Supplied PASS, endpoint, mean and p-value fields are not trusted.

An unclassified search failure retains only the verified prefix through the last delivered observation. Later grid points remain unknown. The runner does not claim it can infer a scientifically justified failure cause from every Python exception. A completed accounted search with no policy is a verified no-policy outcome; a missing protected episode is unresolved. This conservative distinction avoids silently counting an infrastructure loss as a poor method or dropping an adverse method run.

The previous operational 10% unresolved-loss veto remains. A void entry's p-value is set to one for family decision purposes, so it cannot unlock Holm's less stringent second step for another entry. Raw interval rows and per-arm loss counts remain visible. Method/task dependence within a vector is permitted; independence across latent vectors still needs a justified execution design. The code cannot establish it from seed names.

Staging supports joint V04/V05 recomputation from one frozen bundle. The current public campaign wrapper runs an isolated entry and therefore retains .025. A future shared family execution/export must preserve one global search freeze and avoid duplicating differently initialized GP arms; it is not inferred from these utilities. No campaign has run here, so no second Holm step or execution saving has been claimed.

New schema-3 results are routed through the evidence gate and program reader. Acceptance recomputation checks the audited campaign directory and actual phase certificate, checks current source identity, verifies full cost accounting and loss/budget vetoes, and uses the rebuilt statistic.
