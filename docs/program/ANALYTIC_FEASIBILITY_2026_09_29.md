## What mathematics can establish

1. Derive the superiority null, component/family error rules and the logical requirements for a joint claim.
2. Prove a statistical procedure invalid by a counterexample, without running PPO or a large bootstrap simulation.
3. Calculate model-conditional power, uncertainty and task/replicate tradeoffs using scalar distribution functions.
4. Derive the least-cost allocation under explicit variance/cost assumptions, then search admissible integer counts cheaply.
5. Prove deterministic implementation invariants and check reference parity using algebra, enumeration and small fixtures.

These calculations do not supply unknown objective values, between-task variance, runtime or GPU throughput. In particular, no mathematical identity proves that the implemented GP/TPE beats random or Sobol on the declared real workloads. Optimizer regret theorems have assumptions and often conservative bounds; they are not empirical acceptance of this code and task distribution. The remaining task is to collect only the observations needed to resolve those unknowns.

## Exact explanation of the failed bootstrap

Take three independent, identically distributed, continuous symmetric task effects centered at zero, with negligible within-task seed noise. In the ideal task bootstrap, drawing the smallest observed task result three times has probability

\[
(1/3)^3=1/27\approx .03704 > .025.
\]

Consequently the .025 lower percentile of the bootstrap task mean equals the smallest observed task effect. It is positive exactly when all three task effects are positive. Under the null this happens with probability

\[
(1/2)^3=1/8=.125.
\]

Thus the nominal .025 procedure has .125 Type I error in this valid limiting example. The earlier .127 simulated rate is consistent with the proof; it is not necessary to simulate it to establish the defect. Extra seed repetitions or bootstrap draws cannot fix this example. It is a counterexample to the current small-task method, not a universal estimate of its error rate on real tasks.

## Hierarchical uncertainty and analytical power

For one normalized paired-improvement component, use the explicit planning model

\[
D_{tr}=\Delta+U_t+\varepsilon_{tr},\qquad
\operatorname{Var}(U_t)=\tau^2,\quad
\operatorname{Var}(\varepsilon_{tr})=\sigma^2.
\]

There are T independent tasks and n complete paired study blocks per task. Task effects and residuals are independent across the indicated units. Then, without a normality assumption,

\[
\operatorname{Var}(\widehat\Delta)=\frac{\tau^2}{T}+\frac{\sigma^2}{Tn}.
\]

The first term is an irreducible variance floor when only n increases. The second shrinks with seed replication. A large campaign on three tasks can therefore remain inefficient and scientifically inadequate. The paired residual variance already accounts for correlation between arms; counting adaptive trials as independent studies would be invalid.

If independent task effects and residuals are also Gaussian with common component variances, balanced task means are iid normal. A one-sided t test of task means has T−1 degrees of freedom. Its component power is computable by the noncentral-t CDF:

\[
\lambda=\frac{\Delta-m}{\sqrt{\tau^2/T+\sigma^2/(Tn)}},\qquad
\pi=\Pr\{t_{T-1}(\lambda)>t_{1-\alpha,T-1}\}.
\]

Here m is the null margin (zero for the accepted superiority claim). This is an exact power formula **under the stated Gaussian model and t-test procedure**. It is not power for the current percentile bootstrap, proof that selected tasks are iid Gaussian, or coverage under arbitrary heterogeneity/skew/missingness. The task-mean t procedure is a candidate for review, not silently installed as the registered acceptance method.

For the eight required V04 components, let their marginal powers be pi_j. Irrespective of their dependence,

\[
\max\{0,1-\textstyle\sum_j(1-\pi_j)\}
\leq \Pr(\text{all components pass})\leq \min_j\pi_j.
\]

Therefore .975 power in each of eight components is sufficient for a joint lower bound of .80. It is conservative, not a necessary marginal target. We do **not** multiply marginal powers as if comparisons sharing controls were independent. A zero lower bound does not imply actual joint power is zero. Component alpha .025 is a sufficient first Holm step for the two-entry .05 family; the intersection-union null does not require a further alpha/8 correction. Entry-level .80 power is also distinct from .80 probability that the entire gate passes.

For a known-variance normal test, define K = z_(1−alpha) + z_(1−beta/mc), where mc is the number of required components and beta=.20 for the joint sufficient bound. With a common effect gap delta and variance assumptions across those components:

\[
n\ \geq\ \frac{\sigma^2}{T(\delta/K)^2-\tau^2}.
\]

When the denominator is non-positive and within-task variance is positive, no finite number of seed repetitions meets this sufficient bound for that T. K squared is approximately 7.849 for one component and 15.366 for eight at alpha .025. This simple formula is useful for screening; the unknown-variance small-task case requires the noncentral-t calculation or another justified inference. None of these formulas estimates a planning effect from a desired cheap sample count.

## Least-cost allocation

Suppose opening a task has fixed cost c0 (including a fixed pilot, if applicable), and another complete paired block costs c1. For a fixed target variance V,

\[
C=T(c_0+n c_1),\qquad T=(\tau^2+\sigma^2/n)/V.
\]

Differentiating gives the continuous optimum

\[
n^*=\sqrt{c_0\sigma^2/(c_1\tau^2)}.
\]

This applies for positive between-task variance and per-block cost, before integer, finite-task inference, independence, task-availability and protocol constraints. It shows why opening additional eligible tasks can be cheaper than repeatedly studying the same tasks. The actual allocation must be searched over the scientifically permissible task inventory without selecting tasks by observed favorable performance.

Its model-feasible counts are **not a request for those tasks or studies**. We have no matched pilot estimates that justify using these numbers for the actual campaign. Existing 128-step smoke outcomes do not provide that evidence.
