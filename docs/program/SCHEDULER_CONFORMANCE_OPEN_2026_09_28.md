# Remaining scheduler conformance — V02 / REL-01

This is an existing ASHA/median requirement of the master, still unresolved under D-TIERS/D-PROTOCOL. The GP-prior/PASHA/CMA-ES implementation tranche does not complete it. The [bounded counterexamples](evidence/2026-09-28/spec-01/scheduler-conformance-open.json) distinguish scheduler lifecycle correctness from algorithm-reference conformance.

1. The current ASHA and retained budgeted-ASHA promotion policy promotes every configuration while the rung population is no larger than eta. With eta=3 and scores [0,1,2], all three promote. Syne Tune 0.13.0's promotion reference requires at least two values and uses the 1/eta quantile; only the best qualifies in this example. Current deterministic tests intentionally exercise the earlier bootstrap policy, so their passes cannot prove vendor ASHA parity.
2. The optional median rule compares the current point value with other reported values at the same non-rung fidelity, including incomplete trials. Five live reports can stop the fifth trial without any completed reference trial. The survey describes running averages and completed-trial references. Full integration also needs an explicit streaming/completion contract: Study currently submits separate endpoint evaluations at successive fidelities.

Recommended V02 design resolution: specify the chosen promotion reference, underfilled-rung behavior, treatment of a study whose budget cannot produce a full-fidelity trial, and completion/streaming semantics. Then repair the policy and update the corresponding behavioral tests against that frozen reference. Do not change the scientific endpoint by silently accepting an arbitrary lower-fidelity incumbent when the full-budget result is absent. Retain the old bootstrap policy under an explicit compatibility name if migration requires it, as for budgeted ASHA versus progressive PASHA.

This is recorded acceptance/specification debt, not a waiver and not a claim that the implementations have passed V02's full written specification. REL-01 remains dependent on this closure. The protocol reconciliation must include this scope before a final V01/V02/V03 freeze; a fresh run of the older narrow V02 recipe would not resolve these counterexamples.
