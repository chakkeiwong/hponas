## Findings that the design must handle

1. **Task catalog is absent.** `validation/task_registry.py` is a catalog of campaign dispatchers, and `validation/tasks/` contains only `.gitkeep`. V01 currently uses a synthetic quadratic. There is no frozen multi-task acceptance dataset, independent task-cluster inventory, or predeclared numerical scale bounds. A real PPO task remains required in the acceptance set, but one task cannot establish the claimed task-family result. STAT-02 must produce task IDs, acquisition/version/dataset hashes, objective direction, physical domains, and scale bounds before a manifest is runnable.
2. **V05 needs an explicit isolation boundary.** Changing a knob's `transform` changes both GP coordinate encoding and the distribution used by `GPSearcher._sample_random`. Equal optimizer seeds alone do not produce the same initial physical configurations. Recommendation: share a frozen physical initial design between warped and unwarped GP arms, charge those initial evaluations to both arms, and vary only coordinate encoding thereafter. Record this in the candidate design; otherwise the estimand is a combined initialization-plus-model policy, which requires different wording. No protocol silently chooses between those claims.
3. **Matched measured budget is not a trial count.** The new Study configuration budget and cooperative elapsed-seconds cap are distinct. The elapsed cap can overshoot by an in-flight interval and is not GPU occupancy. The comparison must specify its resource measure, common accounting, permitted overshoot, final endpoint extraction, and treatment of lower-bound accounting after crashes. V06's resolved accelerator-seconds requirement cannot be met by renaming this elapsed measure.
4. **V04-T0's secondary remains decision-bearing.** Its normalized regret AUC cannot be demoted to a plot to simplify the gate. Freeze the budget grid, interpolation rule, sign, reference value, aggregation, and superiority threshold before data. The proposed entry-level intersection-union rule requires every declared method/comparator/endpoint component to clear its threshold; optional per-method promotion would need a separate family.
5. **Pilot independence and hierarchy are mandatory.** Pair complete studies by task and optimizer seed, retain full arm pairing, and resample task clusters followed by paired blocks. Pilot, confirmation, and any permitted replication need disjoint seeds. Keep the register's >10% missingness veto, 20-replicate caps, and the proposed per-gate Holm alpha 0.05, 0.80 power, at least five pilot replicates per arm, 10,000 bootstrap draws, 2,000 sizing simulations, and upper-80%-variance planning rule. Scientific definitions and actual certification remain open; no numerical threshold has changed.
