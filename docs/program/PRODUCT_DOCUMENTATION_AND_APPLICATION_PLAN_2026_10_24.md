finished core need not be modified to exercise public caller models. Companion

separately source-bound and tested; it does not inherit core qualification.

overhead and null/adverse results. NAS adds actual trained width/depth changes

example has a 1,200-second ceiling; combined example ceiling 2,400 seconds,
one CPU, no GPU, no network, no sibling imports, no external deployment.
Prepare exact runners and manifests before execution. Existing fixed commands
remain unchanged; request only actual managed approvals if required.
