# STAT-03 deliverables and remaining VAL-01 work

Revision 1.9 supersedes this package's previous requests for the user to choose thresholds, pilot order or uncosted study budgets. The prior version is preserved in `archive/program-2026-09-29/stat-03-before-scientific-sequence/`. The [scientific execution plan](SCIENTIFIC_EXECUTION_PLAN_2026_09_29.md) owns the rationale, calibration finding, phase sequence and resource arithmetic.

This work is **inside the existing master program**. D-T0-CLAIMS remains accepted; the method comparisons do not need another approval. D-T0-DESIGN now assigns scientific derivation and preparation to the implementation agent. D-PILOT-ORDER adopts the external-pilot sequence. Neither decision certifies an unfinished protocol or allocates compute.

| Input or deliverable | Current disposition and owner |
|---|---|
| Superiority threshold | Zero for final quality and regret-AUC improvement, derived from the accepted positive-gain hypothesis. Recorded in the candidate and draft protocol register. |
| Pilot/final sequence | Freeze the pilot and adaptation rule; certify and run the bounded external pilot; size confirmation; freeze and certify confirmation; analyze once. Pilot data never enters confirmation. |
| Task family and independence | Agent prepares the justified independent acceptance set. Ant/HalfCheetah/Hopper are candidates, not evidence for a broad HPO task population. More seeds cannot replace task diversity. |
| Inference and sizing | Agent repairs the failed small-task null calibration, validates composite-boundary error, coverage and joint power, and addresses uncertainty in covariance and power estimates. The present candidate is not scientifically validated. |
| Normalization and planning effects | Agent researches externally justified scales, regret references, initial objective and effects worth detecting, frozen before pilot outcomes. No effect is invented just to fit the sample cap. |
| Resource requirement | Agent prepares a pinned GPU-capable environment, bounded profiling proposal and measured study/overshoot envelope. Current project JAX is CPU-only. Conditional 90-pilot/360-maximum-confirmation arithmetic is documented; no runtime or allocation is fabricated. |
| V01 benchmark/equivalence | Agent selects exact versioned tabular tasks and vendor recipes, exact checks where deterministic, and scientifically justified equivalence/divergence criteria where stochastic. |
| V02 population | Agent freezes the scheduler matrix and generated/event/recovery populations, including appropriate median and PASHA coverage. |
| Optional replication | Agent specifies error control across any permitted stages before first confirmation, or leaves the optional path unused. A one-replication cap alone does not control repeated-testing error. |
| Scientific certification | D-PROTOCOL reviews the complete, concrete phase protocol and resource envelope before campaign spending under policy D5. Preparation continues before that review. |
