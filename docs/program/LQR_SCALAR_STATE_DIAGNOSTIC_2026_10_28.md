# RL-LQR-06: scalar-state and redundant-action diagnosis

## Question and matched cases
The user asks whether ten state dimensions cause the three-action learning gap and whether one state with three actions has the same issues. Freeze three cases: scalar1=(1 observed physical state,1 action); scalar3=(1 state,3 actions); padded3=(10 observed states,3 actions), where the last nine states are irrelevant to both the controlled state and all costs. This is a diagnostic successor, not a repetition or alteration of RL-LQR-05.

The active scalar evolves x_next=.92*x+b*u+.025*sign, b=ones(m)/sqrt(m); initial x is an independent sign times .5. For padded3, nine independent initial-sign nuisance coordinates evolve z_next=.8*z+.025*alternating_sign*sign using the same independent-in-time scalar noise sign. They neither affect x nor enter reward. Q=Q_terminal=diag(1,0,...), R=.1I_m, gamma=.99, horizon30, every action in [-1,1]. Initial sampling always draws ten signs before slicing, so identical evaluation seeds pair the active scalar and noise across cases. Environment resets use the same convention. Nuisance coordinates do not add control information given the active Markov state and time.

The normalized effective action is v=b*u; decompose u=b.T*v+u_perp. Stage cost is x^2+.1v^2+.1||u_perp||^2. The true optimum has u_perp=0. All three cases therefore have the same Riccati cost when the scalar oracle is feasible, which must be certified on all initial/noise paths. Three actions have two redundant directions, not three independently controllable states. The vector box permits |v|<=sqrt(3), versus1 in scalar1; the shared optimal policy must lie inside both, but feasible policy classes and stochastic exploration are not identical. We claim a normalized-optimum diagnostic, not complete dynamic equivalence of action parameterizations.

Padded3 versus scalar3 changes irrelevant observation dimensions while preserving the cost, active law, action coordinates and optimal policy. It isolates sensitivity to representation/nuisance inputs, not the full effect of ten coupled cost-relevant states in RL-LQR-05. Scalar3 versus scalar1 diagnoses redundant-action learning with a fixed effective plant and optimum; entropy target and Gaussian dimension change with action count under unchanged SAC defaults, so it is not an entropy-controlled causal ablation.
