Date: 25 October 2026. Authority: CONSOLIDATED_MASTER_AUTHORITY.md and
docs/program/program.json. This is an authorized successor to SCI-01, not a
replacement for the accepted finite product or its original failures.

## Deliverables and sequence

1. **SCI-02/DESIGN** — archive the completed predecessor, reconcile the SCI-01
   wrapper hash transition without editing consumed evidence, freeze this
   scope and review the arithmetic, scientific claims and resource contract.
2. **SCI-02/IFBO** — implement a versioned companion reconstruction using the
   pinned upstream float32 incumbent and bin operations. Independently compare
   the original upstream PI body with the new reconstruction on all 138 saved
   tensors and replay all six histories. Keep the original 5e-6 PI envelope,
   original performance threshold, FAIL and cancelled integration. No model
   loading, pretrained forward, training update or favorable rerun.
3. **SCI-02/NAS** — make a reusable optional companion checker for a specified
   two-input scalar SiLU network against exp(-x*a), rational rectangle and
   derivative limits. Recompute every interval bound; reject malformed models,
   duplicate/overlapping/incomplete partitions and nonfinite inputs. Explicitly
   return unverified when bounds or resource limits do not prove the claim.
   Replay the six saved networks, compare an independent retained derivation,
   and test negative controls. Qualify only this companion's pinned source,
   interface and tested envelope, not arbitrary architectures or the wheel.
4. **SCI-02/REFERENCES** — implement/test the exact Gaussian-to-banana reference
   and document why it does not prove convergence of existing leapfrog/learned
   kernels. Prepare a prospective wallet decision-regret evaluation: freeze
   selected policies, comparator, estimand, independent observations, missingness
   assumptions, simultaneous uncertainty and stopping before any new data.
   Report sample-size/precision formulas instead of choosing a success effect
   from observed data. No new evaluation observations are allocated here.
5. **SCI-02/AUDIT** — reconstruct all manifests and outputs, test refusal of
   altered evidence, verify source/evidence preservation, summarize the exact
   closed claims and unresolved claims with resumption conditions, then refresh
   the master. **GAP-01/FINAL-AUDIT** remains the final whole-program guard.

## Objective acceptance and limits

- Arithmetic acceptance requires all saved calls within the unchanged numerical
  envelope, source-derived reference agreement and rejection of bad inputs.
  Performance remains a separate failed gate, regardless of arithmetic repair.
- NAS acceptance uses outward interval arithmetic on the exact saved binary64
  constants, a full partition, and the original derivative limits. A loose
  bound means unverified; it does not prove a violating point exists. The claim
  concerns real-valued mathematics, not floating-point evaluation error.
- Exact reference identities concern only the named synthetic distribution.
  R-hat/ESS and testing cannot replace a convergence theorem.
- Wallet future superiority uses a zero utility-difference null, simultaneous
  uncertainty and frozen policies. Finite search regret zero does not establish
  population utility superiority. Unknown MNAR and causal effects remain
  unidentified without additional assumptions or intervention.
- No human approval, test count or completion label determines a scientific
  result. Unfavorable and inconclusive outcomes remain first-class outcomes.

## Bounded operations and phase repair

One inspector/editor, one CPU, one numerical thread, no GPU/network/services.
Each new operation is manifest-bound before launch, maximum 300 seconds except
NAS verification at 600 seconds, maximum 2 GiB owned RSS and 32 MiB output.
Zero training fits, pretrained forwards or sampler chains. Each allocation is
single-use; retain failures and review a successor before any justified retry.
The fixed operation owns its environment and exact test roster. Routine program
checks use the exact commands in docs/PROGRAM_OPERATIONS.md. No global allow
rules, protected configuration, git history, sibling repository or deployment
changes are included. At each boundary repair demonstrated defects, refresh
the next bounded stage and continue. No new broad campaign is authorized.

## Thorough review checklist before execution

Check dependency order, predecessor/evidence immutability, exact float32
operation ordering, numerical-envelope invariance, independent references,
NAS partition coverage and rounding, failure-versus-unverified semantics,
wallet independence/selection/exposure boundaries, exact-flow target/Jacobian,
operation isolation and time/resource limits, explicit source qualification,
and terminal audit coverage. Record findings and corrections separately in
the SCI-02 plan review; do not mark implementation complete at design time.

## Claims outside this allocation

Wallet utility superiority needs fresh independent observations; unknown MNAR
and causal identification need assumptions, intervention or sensitivity bounds.
General sampler convergence needs a target/kernel theorem; ifBO effectiveness
needs a new prospective comparison; unseen NAS seeds, floating-point inference,
real-bank effectiveness and unattended production readiness need their own
contracts and evidence. These are unresolved scientific claims, not completed
features inferred from a terminal administrative audit.
