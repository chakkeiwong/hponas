\section{The direct FinMarketing integration evidence}

The native diagnostic used the actual FinMarketing response fitting and
evaluation path through the public HPO-NAS Study API. It evaluated the declared
fifteen-point regularization grid, then ran random, Sobol, GP and TPE studies
with sixteen proposals per method. All sixty-four search trials completed, a
separate final evaluation followed each persisted selection, and the complete
operation took 9.172 seconds on the recorded machine. The independently
assembled validation log loss differed from the stored value by at most
$1.12\times10^{-16}$. GP spent 5.485 seconds in acquisition and orchestration
outside the objective fits, which is why grid cost and search overhead are
reported separately.

This native run is an integration result, not a replacement for the later
self-contained reproducible examples. The companion response fixture removes
the sibling dependency, uses three fixed data replicates and a protected final
fold, and supplies an independent scalar reconstruction. Neither result claims
that the selected regularization is best for the full FinMarketing project.

\section{What has and has not been tested for RL tuning}

The current real-RL evidence is the V14 bounded CPU PPO walk. It trains one
policy on Brax \texttt{inverted\_pendulum}, writes the learning curve and
checkpoint to the SQLite-backed ledger, and evaluates the frozen checkpoint on
protected seed $999$. Its PASS establishes executable PPO, checkpoint and
search/final seed separation. It does not compare searchers or establish a
best PPO configuration.

Earlier real-PPO random/pathological and GP experiments are retained as
historical diagnostics. They include incomplete or retired comparison paths,
and the original statistical superiority/pilot design was prospectively
retired. They cannot be relabelled as a successful RL tuning study. The
sequential policy companion is a finite MDP tuning test with an exact oracle;
it exercises policy selection and causal safeguards, but it does not train a
neural RL agent.

\section{A minimal RL case suitable for a bounded integration test}

The smallest useful next RL test is a self-contained two-state, two-action,
four-step MDP with deterministic transitions and rewards. Start in $s_0$.
Action $a_0$ gives reward zero and leaves the state unchanged. Action $a_1$
from $s_0$ gives reward one and moves to $s_1$; action $a_1$ from $s_1$ gives
reward two and leaves the state at $s_1$; the remaining state/action pairs give
zero reward and leave the state unchanged. Thus backward induction gives the
known optimal undiscounted return $1+3\cdot2=7$. At each trial a tabular
Q-learning caller is trained from a fixed set of training episodes.
The finite hyperparameter domain is
\[
 \alpha\in\{0.1,0.5\},\qquad
 \epsilon\in\{0,0.1\},\qquad
 N_{\rm episode}\in\{8,32\}.
\]
The tuning score is mean undiscounted return on fixed validation episodes;
final episodes are independent and remain outside the search history. A
backward-induction dynamic program supplies the exact optimal return and the
complete eight-configuration enumeration supplies the finite HPO reference.

This case is small enough to run on one CPU in seconds and still tests the
important interfaces: a caller-owned training loop, maximization, separate
roles and seeds, model and optimizer-state artifacts, work accounting,
checkpoint/resume after an interruption, and refusal of final-data leakage.
The objective is an objective result: the report states the selected return,
finite regret against the eight-point reference and exact dynamic-programming
regret. It has no human acceptance threshold and no claim about PPO or
large-scale RL. A new run would require a versioned bounded manifest and a
successor master stage; it is not silently added to the completed APP-01
allocation.

\begin{decisions}
\textbf{RL disposition.} V14 establishes the bounded real-PPO integration path. The
two-state Q-learning case is the recommended inexpensive known-answer RL
integration test if RL tuning is reopened. Neither result should be described
as universal RL tuning evidence or as production policy performance.
\end{decisions}
